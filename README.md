# 🐦 Fil X / Twitter — Veille technologique

## 📌 Présentation

Ce repository contient le second livrable du projet de veille technologique.

L'objectif est de mettre en place un fil X / Twitter permettant de suivre
des développeurs, mainteneurs, organisations et experts pertinents pour
l'activité de développeur.

Le fil X complète le tableau de bord Feedly en permettant de suivre plus
rapidement :

- les annonces technologiques ;
- les nouvelles versions ;
- les vulnérabilités ;
- les évolutions de projets open source ;
- les discussions techniques ;
- les évolutions de l'intelligence artificielle.

---

# 🎯 Objectifs

Le fil X répond à plusieurs objectifs.

## 🔐 Suivre les acteurs de référence

Le fil permet de suivre directement :

- les mainteneurs de projets open source ;
- les développeurs reconnus ;
- les organismes de cybersécurité ;
- les éditeurs de technologies ;
- les acteurs de l'intelligence artificielle.

---

## ⚡ Détecter rapidement les nouveautés

Les réseaux sociaux permettent de détecter rapidement :

- les annonces ;
- les nouvelles versions ;
- les correctifs de sécurité ;
- les nouvelles fonctionnalités ;
- les publications techniques importantes.

---

## 🗣️ Suivre les discussions techniques

Le fil permet également d'observer les échanges de la communauté autour :

- de PHP ;
- de Symfony ;
- de la cybersécurité ;
- de l'intelligence artificielle ;
- du développement logiciel.
